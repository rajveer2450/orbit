## Highlights

- **Parallel execution** — launch multiple agents across features, fixes, refactors at once
- **Any CLI agent** — agent-agnostic; anything you can run in a terminal
- **Isolated worktrees** — no conflicts until *you* choose to merge, behind a verify gate and a single-writer merge queue
- **One attention queue** — needs-input detection and a stall watchdog keep N workstreams calm
- **Local-first** — your code and sessions stay on your machine; cloud sync is opt-in
